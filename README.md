# 🛒 Smart Trolley and Theft Detection System

An IoT-based Smart Shopping Trolley designed to provide real-time billing, product tracking, and theft detection using RFID technology and ESP32.

## 📌 Project Overview

The Smart Trolley system allows customers to scan products using RFID tags and automatically calculate the total bill. It also includes a theft alert mechanism that detects unauthorized item removal through the trolley's removal monitoring system.

A web-based dashboard displays live billing information and security status.

## ✨ Features

- RFID-based product identification.
- Automatic bill calculation.
- Real-time shopping cart updates.
- Theft alert and unauthorized removal monitoring.
- Buzzer and LED alert system.
- OLED display for trolley information.
- Web dashboard for live monitoring.
- Billing completion and item return authorization.

## ⚙️ How It Works

1. ESP32 connects to the Wi-Fi network.
2. Customer starts the billing session.
3. RFID reader scans product tags.
4. Product name, quantity, and price are updated.
5. Total bill is calculated automatically.
6. Unauthorized removal can trigger a theft alert.
7. Buzzer and LED indicate the alert status.
8. The dashboard displays billing and security information.
9. Billing can be completed after pending removal alerts are cleared.
